SPACEGUESSR 7.1 — OFFLINE CLASSROOM RESOURCE SET

1. Open SpaceGuessr_7_1_Game.html in a modern browser. No server required.
2. Print Student_Investigation_Sheets.pdf (15 individual round sheets).
3. Read Teacher_Guide_and_Answers.pdf and Source_Register.csv.
4. Use question_bank.csv for future SciSims integration.

The game runs entirely on this computer. It does not save scores between reloads; export CSV. External source links require internet. Built-in visuals are original schematics rather than NASA photos. Source image selection, rights/attribution review and cultural source approval are required before replacing them with authentic imagery. The hosted SciSims prototype is index.html; the named HTML remains an alternate offline entry. This publication adds shared SciSims navigation and downloadable companion resources.

Outcomes: SC4-OTU-01 and SC4-WS-08 primarily; not a replacement for assessed practical skills.
