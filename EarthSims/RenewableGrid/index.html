How to use

  • Choose the weather week and build a grid using renewables, batteries and backup power.
  • Run the grid hour by hour, one day at a time, or for the full week.
  • Try to keep demand met without letting emissions or cost become too high. In Student mode, Medium settings should usually work in a typical week.
  • Use Advanced mode only when students are ready for more detailed controls.
Challenge: Keep the grid reliable while reducing emissions and avoiding very high cost. There is no perfect setting: each variable affects supply, storage, cost, emissions or reliability.

What the model shows

Energy systems involve trade-offs. More renewables can lower emissions, but weather changes. More batteries help store energy, but storage is limited. More backup power improves reliability, but it can increase emissions and cost. The aim is to find a balanced solution, not a perfect one.

Teacher notes

  • Designed for Year 8 energy and sustainability discussions. Start in Student mode; use Advanced mode for extension students.
  • The values are classroom model units, not real grid data.
  • Suggested task: students run two different strategies, save each run for comparison, export CSV data, then write a CER response explaining the trade-offs.
  • Extension: compare a high-renewable grid, a high-reliability fossil-backed grid, a storage-heavy grid and a low-cost grid.
