# StudyBoard3000 AMA Board Add-on

Add:
- `templates/teacher-ama.json`
- `instances/teacher-ama-2026.json`

Replace:
- `config/boards.json`

Passwords use the existing `general-2027` access profile:
- Student: `contribute`
- Teacher: `studyboard`

The current GitHub Pages build stores contributions in localStorage. This AMA board is therefore suitable for:
- one shared device;
- a projected board operated by a facilitator; or
- individual offline copies.

Live multi-device collaboration requires a backend and is not included in this add-on.
