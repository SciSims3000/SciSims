# Girder Rush

Classroom prototype for Years 7–10: arrow keys to move/climb, Space to jump, or use the touch buttons. Clear the running-jump shortcut or recover on the lower walkway.

Opening the jump replay pauses play. Resume closes the replay. Horizontal speed stays fixed in flight; compare jumps only when take-off and landing heights match. Distances are game pixels, not calibrated SI measurements. Navigation hides during fullscreen classroom views.

Published in the Physics catalogue and supporting Stage 4 unit 7.2 and Stage 5 unit 10.3.
