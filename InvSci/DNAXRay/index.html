DNA X-ray Diffraction Evidence Builder

Test possible DNA structure models against evidence from chemical composition, Chargaff’s ratios, X-ray diffraction, Photograph 51-style patterns and model building.

Learning Intention

Students will understand that X-ray diffraction provided indirect evidence that helped scientists develop and test models of DNA’s structure.

Success Criteria

Students can compare DNA structure models, use evidence to assess model fit, and explain how technology contributed to the double helix model.

Evidence and model

Current model relationship

X-ray diffraction does not show DNA directly. It creates a pattern that can be used to test which molecular structure best explains the evidence.

Assessment question: Which evidence source had the greatest impact on the double helix model, and why?

Best evidence for this model

The double helix model is strongest when X-ray diffraction, base ratios, molecular width and model building all fit together.

Model feedback

Add evidence to see whether the selected model is supported, weakened or refined.

Technology impact

X-ray diffraction allowed scientists to collect indirect structural evidence from molecules too small to see with light microscopes.

Investigation steps

  1. Select a DNA structure model.
  2. Add one evidence source at a time.
  3. Compare the diffraction pattern and model fit.
  4. Assess which evidence most strengthened the model.

Model limitation

This is a simplified teaching model. It shows how evidence constrains models, but it does not calculate real crystallographic data.

Student challenge

  1. Test the single helix, triple helix, flat ladder and double helix models.
  2. Add X-ray diffraction evidence and explain why the X-shaped pattern supports a helical structure.
  3. Add Chargaff’s base ratios and explain why base pairing supports the double helix model.
  4. Use an assessment lens to decide which technology or evidence source had the greatest impact.
  5. Evaluate the simulation: what does it help explain, what does it simplify, and how is it different from real X-ray crystallography?

CER response

Teacher notes

  • Suggested primary module: Investigating Science Module 6, Technologies. Strong cross-module link to Module 4, Theories and Laws.
  • The focus is how X-ray diffraction technology contributed evidence for a scientific model, not the detailed mathematics of crystallography.
  • The diffraction image is symbolic and does not reproduce Photograph 51 or real X-ray crystallographic calculations.
  • Useful discussion points include Rosalind Franklin and Raymond Gosling’s X-ray diffraction work, Chargaff’s base ratios, model building, data interpretation and ethical acknowledgement of evidence.
  • Students should assess the simulation itself by discussing strengths, limitations, differences from real investigations, possible sources of error and overall usefulness.
  • Source base: King’s College London Photograph 51 resources, Nature 1953 DNA structure papers and Nobel Prize 1962 resources.
