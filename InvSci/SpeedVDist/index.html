Speed vs Distance Investigation

Design a practical investigation using available technologies to measure the independent variable speed and the dependent variable distance travelled in a fixed time.

Investigating Science Technologies Quantitative data Speed graphs

Learning Intention

Students will understand how a practical investigation can use technology to measure both speed and distance travelled, producing quantitative data that can be graphed and evaluated.

Success Criteria

Students can identify the independent and dependent variables, choose suitable measuring technologies, collect repeated quantitative data, calculate means and use a graph to describe the relationship.

Practical investigation design prompts

Aim

Investigate how changing the speed of a trolley affects the distance it travels during a fixed time interval.

Hypothesis

As speed increases, distance travelled will increase. If the time interval is kept constant, distance should be directly proportional to speed.

Method outline

Use a launcher or ramp to give different speeds. Measure speed at the start with a photogate or video analysis, then measure distance after the same time interval using a motion sensor, video analysis or tape measure.

Reliability

Repeat each speed setting at least three times and calculate a mean. Identify outliers caused by poor release, sensor error or track obstruction.

Validity

Only change trolley speed. Keep the trolley, surface, time interval, start line, sensor positions and release direction constant.

Risk management

Use a low-speed trolley, keep the track clear, stop the trolley before the table edge, secure cables and avoid standing in the path of motion.
