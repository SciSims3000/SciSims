Touch Pad Synth Simulator

A simple X-Y synth inspired by touch-pad instruments. X controls scale-quantised pitch, Y controls filter brightness, with hold mode and a basic loop recorder.
Touch Pad
Move across the pad for pitch. Move upward for a brighter sound. Click, drag, or use touch. Headphones help if you are using a laptop speaker with low bass response.
