Coefficient
The large number placed before a formula. It changes the number of particles.
Subscript
The small number within a formula. It is part of the substance and must not be changed.
Balanced
The number of each type of atom is equal on both sides.
How to balance efficiently
  • Count every element on both sides.
  • Begin with an element that appears in the fewest substances.
  • Change coefficients only.
  • Recount after every change.
  • Finish with the lowest whole-number ratio.
