How to use this activity

Students should look for the pattern between structure, bonding and observable properties. The goal is not just to name the bond type; it is to justify the answer using test results.

  1. Use Build a bond to compare particle models.
  2. Use Test unknowns to collect evidence from material properties.
  3. Use Challenge mode to apply the patterns to new cases.

Teacher notes

Suggested use: 15–25 minutes. Students can work in pairs, collect evidence for each unknown, then write a short claim-evidence-reasoning paragraph: The material is likely _____ because _____.

Learning intention

Students investigate how the arrangement of particles and electrons in ionic, covalent and metallic bonding helps explain the properties of materials.

Success criteria

  • I can describe electron transfer, electron sharing and delocalised electrons.
  • I can connect bonding and structure to properties such as conductivity, melting point, solubility and brittleness.
  • I can justify a bond type using evidence from more than one test.

Built-in simplifications

This is a Stage 5-style model. Real materials can be more complex. Graphite, alloys, polar molecules and intermediate bonding are deliberately avoided in the main unknowns so that students can first learn the core patterns.

Source basis: NSW Science 7–10 Syllabus organisation and Working scientifically emphasis; Royal Society of Chemistry structure and bonding resources; LibreTexts introductory chemical bonding explanations. The activity uses simplified school-level bonding models for classroom learning.
