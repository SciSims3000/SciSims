Challenge questions

Teacher notes

Core idea: Dynamic equilibrium occurs in a closed system when the forward and reverse reactions continue at equal rates, so the concentrations of reactants and products remain constant overall.
Key misconception: Constant concentrations do not prove that the reaction has stopped. In a dynamic equilibrium, particles are still changing between reactants and products.
Open-system contrast: In this model, product particles can escape from the open container. Because the reacting mixture is no longer fully contained, it should drift rather than settle into true chemical equilibrium. This is different from a steady state in some advanced open-system contexts.

How to use this sim

  • Start with a closed system and dynamic model.
  • Watch the forward and reverse event counts. They should become similar over time.
  • Compare the dynamic model with the static comparison model.
  • Switch to an open system and observe the product escaping.
  • Use Add A, Add B and Remove B to disturb the system.
  • Use both graphs as evidence: constant concentrations plus similar forward and reverse event counts.

Student self-test

  • Explain why equilibrium is described as dynamic.
  • Explain why a closed system is needed for chemical equilibrium.
  • Describe the evidence that shows equilibrium has been reached.
  • Compare a static model with a dynamic equilibrium model.
  • Predict what happens in this product-escape open-system model.
  • Explain why equal rates do not always mean equal amounts of reactants and products.

Source notes

This model is based on standard descriptions of chemical equilibrium as a state in which forward and reverse reactions occur at equal rates and concentrations remain constant in a closed system. The open-system section is a simplified product-escape contrast model. Useful teacher references: Chemistry LibreTexts: Chemical Equilibrium, Monash University: Dynamic equilibrium, and Chemguide: Introduction to chemical equilibria.
