Sneeze: Infection Spread Game

This page uses Ruffle to run an archived Flash-based disease transmission game in a modern browser.

Learning Intention Students will understand that infectious diseases can spread through a population when infected individuals come into contact with others.
Success Criteria Students can explain how movement, timing, contact and transmission affect the spread of infection in a population model.
Teacher note: frame this as a disease transmission model. The game places the player in control of infection spread, so it is best used to discuss how hygiene, isolation, contact patterns and timing can affect outbreaks.

If the simulation does not load, wait a few seconds and refresh the page. The SWF file must be in the same folder as this page and named sneeze.swf.
