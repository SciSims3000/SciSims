Ginger Dawn: Genetics Game

This page uses Ruffle to run an archived Flash-based genetics game in a modern browser.

Learning Intention Students will understand that inherited traits are influenced by genes and that some traits can follow predictable inheritance patterns.
Success Criteria Students can connect the game scenario to genetic inheritance, recessive traits, variation and the way traits may appear in a population.
Teacher note: preview the full game before classroom use. This activity is best framed as a light genetics discussion starter rather than a full scientific model of inheritance.

If the game does not load, wait a few seconds and refresh the page. The SWF file must be in the same folder as this page and named gingerdawn.swf.
