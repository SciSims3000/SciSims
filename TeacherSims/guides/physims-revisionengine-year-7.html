Assessment & revision · Teacher guide

Year 7 Revision Engine

Practise numerical science skills at an appropriate level.

Suggested time: 10–20 min

Open tool

Quick start

  1. Choose calculation topics, difficulty and question count.
  2. Start with Practice, then Check answer and Show working after a genuine attempt.
  3. Use Start quiz for a short check or Download question set for paper practice.

Try it in class

Ask students to show the calculation, units and a sentence explaining what the result means.

Save and reuse

Save the quiz JSON report or print to PDF. Load downloaded question sets in Worksheet Builder.

Tips and troubleshooting

Select at least one topic. Adaptive question-set downloads use Standard difficulty; read units carefully.
