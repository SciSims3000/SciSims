Classroom routines · Teacher guide

Science Magic 8-Ball

Use a playful random answer as a discussion hook.

Suggested time: 2–3 min

Open tool

Quick start

  1. Enter an optional question and choose a colour scheme.
  2. Select Shake for an answer, click the ball or press Space.
  3. Ask students whether the result has any evidential value and how the question could actually be investigated.

Try it in class

Contrast a random verdict with a testable prediction supported by evidence.

Save and reuse

Copy any useful question into your own notes; use the tool for the live moment.

Tips and troubleshooting

Answers are random. Use it only for trivial choices or discussion, never assessment or safety decisions.
