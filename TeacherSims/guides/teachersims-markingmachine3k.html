Discussion & reasoning · Teacher guide

AI Marking Machine 3000

Use parody to discuss what valid assessment actually requires.

Suggested time: 5–10 min

Open tool

Quick start

  1. Choose a faculty, course, question type, key verb and marks available.
  2. Select a marker preset and engine, then MARK THIS MASTERPIECE.
  3. Contrast the nonsense mark with the serious Actual Marking Thought.

Try it in class

Ask what evidence a real marker would need and how criteria should connect to the response.

Save and reuse

Record useful assessment-literacy discussion points, not the generated mark.

Tips and troubleshooting

No student response is evaluated. This is a parody and must not be used for actual assessment.
