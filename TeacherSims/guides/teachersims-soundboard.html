Classroom routines · Teacher guide

Teacher Soundboard 3000

Use short sounds or spoken phrases for familiar classroom cues.

Suggested time: 1–3 min setup

Open tool

Quick start

  1. Set Volume and test a sound before the lesson. Choose a voice delivery if using speech.
  2. Select a sound or use shortcuts 1–8. Escape or Stop all stops playback.
  3. Use favourites for regular cues. Add phrase or Upload audio for your own material.

Try it in class

Agree on one sound for attention and another for transitions; keep their meanings consistent.

Save and reuse

Public phrases and favourites save on this device. Custom audio and private additions last only for the session. Use Export JSON for supported portable content.

Tips and troubleshooting

If silent, check device volume and interact with a sound button first. Teacher Mode hides additions on screen; do not rely on it as account security.
