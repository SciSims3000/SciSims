HSC Chemistry Revision Engine

Practise HSC Chemistry calculations with worked feedback.

Suggested time: 15–25 min

Open tool

Quick start

  1. Select calculation topics, difficulty and question count.
  2. Use Practice to attempt, Check answer, Hint and Show working.
  3. Choose Quiz and Start quiz for a set; review results and identify calculations to revisit.

Try it in class

Require units and a written explanation of the chemical relationship behind the calculation.

Save and reuse

Download JSON report or Print / Save as PDF after a quiz. Download question set opens in the linked Worksheet Builder.

Tips and troubleshooting

Select at least one topic. Scientific notation such as 1.2e-5 is accepted. The displayed engine targets the 2017 syllabus.
