Revision Engine Worksheet Builder

Turn supported Revision Engine exports into a printable student sheet and separate answer key.

Suggested time: 5–10 min setup

Open tool

Quick start

  1. Download a question set or completed quiz JSON report from Physics, Chemistry or Year 7 Revision Engine.
  2. Load it using Revision Engine JSON file. Select all, missed or individual questions.
  3. Choose Student worksheet or Teacher answer key, then Print / Save as PDF.

Try it in class

Print missed questions as a targeted follow-up, with students explaining the correction.

Save and reuse

Keep the source JSON and save the printed PDF. Files are read in your browser.

Tips and troubleshooting

This builder expects supported engine exports, not an arbitrary JSON question bank. Biology and EES have their own worksheet controls.
