Science games · Teacher guide

Science Codebreaker

Use evidence to eliminate possibilities and improve a hypothesis.

Suggested time: 10–15 min

Open tool

Quick start

  1. Choose theme and difficulty, then New game.
  2. Select symbols in order and Test hypothesis. Green counts correct symbol and position; amber counts correct symbol in the wrong position.
  3. Use the investigation log to plan the next test. Copy current code for a shared classroom challenge.

Try it in class

Before each guess, ask which possibilities it will eliminate and why it is more informative.

Save and reuse

Keep the classroom challenge code to reproduce the puzzle.

Tips and troubleshooting

Feedback totals do not identify individual positions. Read the displayed repeat rule; avoid interpreting feedback as a position-by-position key.
