Quick start

  1. Open Question Library from the landing page.
  2. Read the linked Teacher Guide and Tab and Column Guide before assembling a set.
  3. Give students the linked Student Guide for selecting, completing and reviewing questions.

Try it in class

Select a small set around one skill, then compare student responses with the expected criteria.

Save and reuse

The working question banks remain in Google Drive. Use the linked library’s workflow for saving your selection.

Tips and troubleshooting

This page is a pilot hub, not a finished automatic exam generator. Access to the linked Drive resources depends on their sharing settings.
