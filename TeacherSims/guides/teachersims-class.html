Class organisation · Teacher guide

SciSims Class

Manage one shared class across seating, grouping and Everybody Thinks.

Suggested time: 5–10 min setup

Open tool

Quick start

  1. Create a class or Import class from Excel / CSV. Use First Name, Last Name, Student ID and Class headings; Excel reads the first worksheet.
  2. Check names and attendance. Add scores and together/apart rules only when needed.
  3. Open Seating plan, Group maker or Everybody Thinks. Select Student display before projecting teacher planning information.

Try it in class

Use the same attendance list for group work and follow-up questioning without re-entering names.

Save and reuse

Export full class v2 preserves attendance, scores, rules and module state/history. Export legacy class list v1 keeps basic class details, names and IDs for standalone tools.

Tips and troubleshooting

Browser saving does not synchronise devices. Student display conceals controls but is not password protection. If mandatory rules block generation, resolve the conflicting rules.
