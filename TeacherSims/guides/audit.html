Teacher tools audit

28/11/2026 · Guide and index coverage audit

Coverage

All 21 top-level TeacherSims tools are represented in the Teacher Tools index. The index also includes 11 related tools elsewhere: 32 tools in total. Embedded SciSims Class modules are covered by the Class guide; data files and the JSON-bank reference are support resources, not additional tools.

Every listed tool now has a dedicated quick-start guide, a direct in-tool link that opens in a new tab, and a guide link on its index card. Existing instructions and linked documents are retained.

Findings teachers need to know

  • Saving varies: some tools retain browser progress, while SciSlide custom challenges need an exported pack. Each guide states the relevant workflow.
  • SciSims Class full v2 and legacy v1 exports preserve different amounts of information. Seating Plan Maker also distinguishes one-workspace sharing from a complete backup.
  • Practice Exam Builder remains a pilot hub; Animation Lab custom exports require its local helper.
  • Spot the Mistake and written Biology/EES responses require human assessment. Marking Machine is explicitly a parody.
  • Some pages already contain useful help, but access and structure were inconsistent. These guides provide a common entry point.

Scope of verification

Inventory and guide content were checked against the repository source. Guide coverage, local destinations, page structure and preservation of the existing tool code were checked. This is not a complete gameplay, accessibility or scientific-content audit; external Drive permissions and every classroom workflow have not been retested.
