Class organisation · Teacher guide

Random Group Maker

Create classroom groups with attendance, rules, locks and roles.

Suggested time: 3–5 min setup

Open tool

Quick start

  1. Paste names or select a saved class. Choose Number of groups or Students per group.
  2. Enable only the optional controls you need: attendance, together/apart rules, recent-pairing avoidance or roles.
  3. Choose Make groups. Review the result, lock students or groups to retain them, and Reshuffle if needed.

Try it in class

Assign a practical group a facilitator, equipment manager and recorder, then project the groups and start the group timer.

Save and reuse

Save class retains the class locally. Copy or Print the groups for a record. SciSims Class provides a shared class workflow and portable full backups.

Tips and troubleshooting

If grouping cannot satisfy your setup, check absent students, conflicting rules, group size and locks. Review the result before using it.
