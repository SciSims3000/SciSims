Class organisation · Teacher guide

Seating Plan Maker

Plan a flexible room layout and project a student-facing seating display.

Suggested time: 5–15 min setup

Open tool

Quick start

  1. Load or paste the class, check attendance and choose Quick layout or Custom room.
  2. Place students by clicking a name then a seat, or dragging. Lock seats to protect them before randomising unlocked seats.
  3. Save the workspace. Exit planning mode and use Student display or Split-screen view for the lesson.

Try it in class

Display the seating plan with the lesson task and timer, then use the random picker for questioning.

Save and reuse

Share workspace JSON exports the current class and room tabs. Backup all JSON protects every saved class and workspace on this device.

Tips and troubleshooting

Attendance here is not an official record. Planning notes are not encrypted. For EDI selection, complete comparable scores for present students first.
