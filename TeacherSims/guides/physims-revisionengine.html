Assessment & revision · Teacher guide

HSC Physics Revision Engine

Practise Year 12 Physics calculations and explain the reasoning.

Suggested time: 15–25 min

Open tool

Quick start

  1. Choose module, calculation topics, difficulty and question count. For motion, select the launch situation.
  2. Use Practice for supported work or Start quiz for a set. Submit answers and explanations where requested.
  3. Review worked solutions. For projectile motion, use trajectory playback and the slider to connect graphs and quantities.

Try it in class

Ask students to predict horizontal and vertical velocity at the highest point before inspecting the trajectory.

Save and reuse

Download a JSON quiz report or Print / Save as PDF. Download question sets for Worksheet Builder; an existing Word guide is linked in the engine.

Tips and troubleshooting

Use the displayed assumptions: g = 9.8 m/s², degree mode, upward/forward positive and no air resistance. Trajectory axes scale independently.
