Science games · Teacher guide

Food Web Builder

Build evidence-based feeding relationships and investigate disturbance.

Suggested time: 15–25 min

Open tool

Quick start

  1. Choose an ecosystem and start with Chain. Read field observations, then select the food first and the eater second.
  2. Use Check web. In Audit and Investigate, remove unsupported links and add missing ones using the observations.
  3. After verification, use the Disturbance lab and answer the investigation questions.

Try it in class

Predict direct and indirect effects of removing an organism, then trace which energy routes remain.

Save and reuse

Progress stays on this device. Have students record a labelled web and their explanation in notebooks.

Tips and troubleshooting

Arrows show energy transfer from food to eater. Losing a route in this simplified model does not establish certain extinction. Revealing the full field guide costs a hint.
