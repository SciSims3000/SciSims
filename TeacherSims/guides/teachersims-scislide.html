Science games · Teacher guide

SciSlide

Reconstruct an image, then explain the science it represents.

Suggested time: 10–20 min

Open tool

Quick start

  1. Choose focus area, image challenge, board size and scramble level; select Shuffle.
  2. Solve the sliding puzzle. Use Preview image or Undo for support.
  3. Write and submit an explanation before reading the model, then complete self-assessment and reflection.

Try it in class

Use a familiar diagram and ask students to connect the rebuilt image to the overarching question.

Save and reuse

Custom challenges are held only in the page: Export JSON pack before leaving. Written responses are lost on changing challenges or reloading; record them separately.

Tips and troubleshooting

Imported photographs are centre-cropped. Add a question, model explanation, success criteria and source/licence when creating your own challenge.
