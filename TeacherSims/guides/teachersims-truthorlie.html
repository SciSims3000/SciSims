Discussion & reasoning · Teacher guide

Truth or Lie

Judge a statement and justify the decision with evidence.

Suggested time: 5–15 min

Open tool

Quick start

  1. Choose the class name, bank, topic, statement count, play mode and thinking time.
  2. Start round. Give everyone thinking time before selecting Truth or Lie; teams take turns.
  3. Ask students to correct false statements, then Reveal explanation and move to Next statement.

Try it in class

Have students commit to an answer individually, compare reasons in pairs, then discuss.

Save and reuse

Export results CSV after the round. Use the editor or Import JSON for custom banks, and Export selected bank to back them up.

Tips and troubleshooting

Thinking time is protected discussion time, not an answer deadline. Each correct answer earns one point; discussion mode has no scores.
