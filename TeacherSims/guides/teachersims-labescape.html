Science games · Teacher guide

Lab Escape

Solve linked science puzzles by collecting and using evidence.

Suggested time: 20–40 min

Open tool

Quick start

  1. Choose New mission and a shared mission number if everyone should receive matching puzzles.
  2. Select a room station, read its evidence and solve the puzzle. Record rewards and clues in the research notebook.
  3. Use Evidence & inventory to solve later puzzles, open rooms and decode the exit.

Try it in class

Work in pairs with one evidence recorder and one operator; swap roles when entering a new room.

Save and reuse

Progress stays on this device. Record the mission number for matching puzzles; starting a new mission replaces the current run.

Tips and troubleshooting

There is elapsed time but no countdown. When stuck, revisit evidence from earlier stations before using a hint.
