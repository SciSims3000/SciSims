Discussion & reasoning · Teacher guide

Science Would You Rather

Develop a reasoned position through science-themed choices.

Suggested time: 5–10 min

Open tool

Quick start

  1. Choose a category and select New question.
  2. Read both choices, allow thinking time and record votes with Vote A or Vote B.
  3. Select Reveal discussion prompt and ask representatives to justify their choices. Reset votes for a fresh vote.

Try it in class

Ask students to vote, discuss the trade-offs, then vote again and explain any change.

Save and reuse

Record the class’s reasons on the board or in notebooks; the useful output is the reasoning.

Tips and troubleshooting

The choices are deliberately difficult. Judge explanations using science rather than treating the more popular option as correct.
