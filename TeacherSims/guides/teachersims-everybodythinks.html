Discussion & reasoning · Teacher guide

Everybody Thinks

Give everyone thinking time before selecting a student to respond.

Suggested time: 5–15 min

Open tool

Quick start

  1. Prepare the student and question lists in the tool; review the prompts before the lesson.
  2. Set the think timer and start a round. Let students think before the student selection.
  3. Use Auto run student drop or select manually after the timer. Choose Next question or Same question · another student.

Try it in class

Ask all students to jot down a response, then invite the selected student to explain and another to build on it.

Save and reuse

Use the list/bank JSON import and export controls for portable copies. For shared class management and full module backups, use SciSims Class.

Tips and troubleshooting

If Remove questions after use is enabled and the pool is empty, use Reset questions. Selection supports participation; it is not a mark of student ability.
