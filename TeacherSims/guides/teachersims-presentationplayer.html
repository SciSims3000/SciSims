SciSims Presentation Player

Present slides with visible Student Engagement Norms.

Suggested time: 2–5 min setup

Open tool

Quick start

  1. Paste a viewable Google Slides link or supported public PowerPoint URL into Slides / PowerPoint URL.
  2. Select Open slides, then navigate using the embedded presentation’s own controls.
  3. Choose icon colour and position; hover for explanations or click to pin one. Use Fullscreen when ready.

Try it in class

Pin the relevant engagement norm before students begin a paired or independent task.

Save and reuse

Keep the original presentation link in your lesson plan. This player displays the source presentation; edit the slides in their original application.

Tips and troubleshooting

If embedding is blocked, use Open in Google Slides. Private files and local PowerPoint files need appropriate accessible links or sharing permissions.
