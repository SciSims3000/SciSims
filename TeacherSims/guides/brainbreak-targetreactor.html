Science games · Teacher guide

Target Reactor

Practise numerical fluency and explain mathematical strategies.

Suggested time: 5–15 min

Open tool

Quick start

  1. Choose difficulty, dice count, dice rule, allowed working and countdown, then New puzzle.
  2. Tap or drag dice, add operators and brackets, and choose Check equation.
  3. Compare alternative solutions. Use Copy classroom code to share the same puzzle.

Try it in class

Have pairs explain the order of operations and why each die is used legally.

Save and reuse

Scores save in this browser when available. Keep the classroom code to reproduce a shared puzzle.

Tips and troubleshooting

Each chosen die can be used once; digits cannot be joined. Settings apply to the next puzzle. A revealed solution earns no points.
