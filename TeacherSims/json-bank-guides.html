Teacher guides to SciSims JSON banks

A JSON bank is a plain-text file containing reusable questions or starter words. Download or export a bank from your tool, edit a copy in a plain-text editor and save it with a .json extension. Keep the schema, field names, double quotes and brackets. Import and test one item before building the full bank.

  • Spot the Mistake
  • Truth or Lie
  • Would You Rather?
  • Science Letters

Spot the Mistake and Truth or Lie share a format. Give each bank a distinct ID using letters, numbers, hyphens or underscores, and give each item a unique ID within the bank. Optional fields are stage and source. Source URLs use HTTP or HTTPS.

Spot the Mistake

Ask students to find the error, correct it and explain why the correction works.

Open Your own question banks. Export a bank to start, or copy the example below. Put the mistake in lie, the correction in truth and the reasoning in explanation. Import your file, select the bank and check the revealed correction.

{
  "schema": "scisims-truth-or-lie-1",
  "id": "geography-map-scale",
  "title": "Map scale",
  "items": [
    {
      "id": "scale-1",
      "topic": "Map scale",
      "lie": "On a 1:50,000 map, 2 cm represents 100 metres.",
      "truth": "On a 1:50,000 map, 2 cm represents 1 kilometre.",
      "explanation": "Multiply 2 cm by 50,000 to get 100,000 cm, then convert to 1 km."
    }
  ]
}

Truth or Lie

Ask students to judge a claim and explain which evidence or rule supports their decision.

Open Your own question banks. Export a bank to start, or copy the example below. Write a true statement and a plausible false version. Write an explanation that makes sense whichever statement appears. Import and select the bank, then play a sample round.

{
  "schema": "scisims-truth-or-lie-1",
  "id": "history-primary-sources",
  "title": "Primary sources",
  "items": [
    {
      "id": "source-1",
      "topic": "Source usefulness",
      "truth": "A primary source can be useful even when its author has a strong point of view.",
      "lie": "A primary source with a strong point of view has no value to a historian.",
      "explanation": "The source can reveal the author's perspective. Compare it with other evidence to test what it establishes about events."
    }
  ]
}

Open Truth or Lie

Would You Rather?

Ask students to choose between two defensible options, vote and justify a trade-off.

Under Custom JSON bank, download the template. Add a prompt, two options, an explanation and a follow-up question in think. Import the file and check the vote and explanation screens. Export your custom bank to share it, or choose Use built-in content to return to the original questions.

{
  "schema": "scisims-would-you-rather-1",
  "title": "Commerce stall decisions",
  "items": [
    {
      "prompt": "Which approach would you try first at a school stall?",
      "optionA": "Sell more items at a lower margin.",
      "optionB": "Sell fewer items at a higher margin.",
      "explanation": "A lower price can increase demand. A higher margin earns more per sale. Total profit depends on sales and costs.",
      "think": "What would change your decision if unsold stock could not be kept?"
    }
  ]
}

Open Would You Rather?

Science Letters

Use familiar subject words to generate letter sets, then ask students to explain why their answers fit the topic.

Under Custom JSON bank, download the template. Set the title to your topic and add words of 2–9 letters each. Use single words without spaces, punctuation or numbers. Import the file and check that your topic appears in the topic menu. Finish scoring the current round before changing banks. The bank supplies starter words for the tiles. Teachers can accept other playable words that fit the topic.

{
  "schema": "scisims-science-letters-1",
  "title": "Music",
  "words": [
    "rhythm",
    "melody",
    "tempo",
    "chord"
  ]
}
