Shared relationship rules · teacher only

Mandatory rules are enforced in seating and grouping. In seating, “together” means neighbouring seats or the same desk/pod, following the existing room layout. In groups it means the same group. Absent students’ rules remain saved but inactive.

    Portable JSON and privacy

    Class data stays in this browser. No student data is transmitted. Export a backup before clearing browser data or changing device. Teacher controls are concealed in student display; this is a display safeguard, not an account or password boundary on a shared device.

    Full v2 exports preserve attendance, scores, rules, metadata and each module’s state/history. The v1 compatibility export contains only names, IDs and basic class details; it works with all three standalone tools. Everybody Thinks list exports are also accepted.
