Guitar String Vibration

Pluck a virtual guitar string and explore how frequency, pluck position, damping and harmonics change the shape, motion and sound of a vibrating string.

Physics Sound Waves Frequency Harmonics

Learning Intention

Students will understand how a vibrating string produces sound and how frequency, damping and harmonics affect pitch and tone.

Success Criteria

Students can describe how changing frequency changes pitch, how damping changes sustain, and how harmonics affect the shape and tone of the string vibration.

Student challenge

  • Change the frequency. What happens to the pitch of the sound?
  • Move the pluck position towards the middle. How does the tone change?
  • Move the pluck position near one end. What happens to the shape and brightness?
  • Increase damping. Does it mainly affect pitch or sustain?
  • Turn on reference node markers and explain why the fixed ends are always nodes.

Teacher notes

This sim links sound, pitch, frequency, resonance, standing waves and harmonics. It also helps students distinguish pitch, loudness, sustain and tone quality.

  • Good prompt: What changes when pitch changes?
  • Good prompt: Why does the same frequency not always sound exactly the same?
  • Extension: Compare a centre pluck with an end pluck using the harmonic controls.

Formula used in the model

The string shape is built by adding standing-wave modes together.

Core idea: a plucked string can be modelled as a sum of standing waves Fundamental frequency: f₁ = main pitch of the string Harmonics: f₂ = 2f₁ f₃ = 3f₁ f₄ = 4f₁ Standing-wave pattern: fixed ends are nodes some points move more than others In this sim: sound uses the selected frequency visual motion is slowed for learning more harmonics = more complex shape and tone greater damping = vibration fades faster higher frequency = higher pitch

How to explain it to students

  • Frequency controls pitch.
  • Amplitude controls how far the string moves.
  • Damping controls how quickly the vibration dies away.
  • Harmonics add detail to the string shape and tone.
  • Reference nodes mark possible fixed points in standing-wave patterns.
  • Pluck position changes which harmonics are strongest.
