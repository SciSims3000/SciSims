Ticker Timer Simulator

Generate ticker-timer tapes at 50 Hz and analyse the spacing between dots. Compare constant speed, acceleration and slowing-down motion using one or two virtual tapes.

Learning Intention

Students will understand how ticker-timer dot spacing can be used to describe speed and changes in speed.

Success Criteria

Students can interpret dot spacing, group dots into equal time intervals, calculate average speed, and compare constant speed, acceleration and deceleration.

Units

Speed is measured in cm/s. Acceleration is measured in cm/s². The ticker timer creates 50 dots each second, so one dot is made every 0.02 s. A 5-gap group takes 0.10 s.

Ticker tape model

The tape moves past a timer that marks a dot every 0.02 s. Wider spacing means the tape was moving faster. A 5-gap group uses 6 dots as endpoints.

Student challenge

  • Run a constant-speed tape. What pattern do the dot spacings make?
  • Run an accelerating tape. How do the dot spacings change over time?
  • Set a negative acceleration. What happens when the tape slows to a stop?
  • Turn on 5-gap groups. Use the table to compare average speed across each group.
  • Export the CSV and graph position against time in a spreadsheet.

Teacher notes

This sim supports practical investigation planning and data analysis. Students can use grouped dot distances to estimate speed over equal time intervals.

  • Good prompt: How do you know the tape is moving faster or slower?
  • Good prompt: Why does a 5-gap group use 6 dots as endpoints?
  • Extension: Compare ticker-timer data with a distance-time or velocity-time graph.

Formula used in the model

The sim calculates position from initial speed, acceleration and time. A new dot is placed every 0.02 s. If negative acceleration would make the speed fall below zero, the tape stops instead of reversing.

Ticker timer frequency = 50 Hz Dot interval: Δt = 1 ÷ 50 Δt = 0.02 s Position while moving: x = ut + ½at² Speed while moving: v = u + at If acceleration is negative: stop time = u ÷ |a| After stop time: v = 0 x = stopping distance 5-gap group time: 5 × 0.02 s = 0.10 s Average speed for a 5-gap group: speed = 5-gap distance ÷ 0.10 s

How to explain it to students

  • Equal dot spacing suggests constant speed.
  • Increasing dot spacing suggests acceleration.
  • Decreasing dot spacing suggests slowing down.
  • Repeated dots at the same place show that the tape has stopped.
  • 5-gap groups make equal 0.10 s intervals, so students can compare distances directly.
  • Model limitation: this is an idealised ticker timer, so it does not include friction, paper drag or mechanical timing error.
